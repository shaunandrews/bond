# Bond Product Brief

## Purpose
Bond is a local-first desktop assistant that keeps work moving across continuous conversation, approved computer access, durable memory, collections, Sense, and media.

## User
A technically capable individual working across code, research, personal operations, and creative tasks. They need an assistant that preserves context without hiding control.

## Core jobs
- Continue meaningful work without reconstructing context.
- Inspect, search, and act on local work with explicit permission boundaries.
- Recall what happened, what matters, and where information lives.
- Track personal entities through collections without turning Bond into a separate database product.
- Move between desktop and a paired LAN device without fragmenting the session.

## Product rules
- **Consent is visible.** Permission level, pending approval, active work, and failure state stay visible at the point of action.
- **Conversation is primary.** Memory, Sense, media, and collections support the task; they do not compete with it.
- **Local proof matters.** Local storage and processing are product value, not implementation trivia. Privacy-sensitive surfaces state scope, retention, and control plainly.
- **Prefer familiar tools.** Use native desktop and conventional editor affordances before inventing interaction patterns.

## Boundaries
Bond is not a novelty chatbot, an opaque autonomous coding agent, an Airtable clone, or a dashboard for every capability.

## Success
A user can resume work, understand what Bond is doing, approve consequential actions, retrieve prior context, and return to the task without training.
