# Field Manual

Current product surface:

## Shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘B` | Toggle sidebar |
| `⌘⇧B` | Toggle right panel |
| `⌘N` | New chat |
| `⌘,` | Settings |
| `Escape` | Cancel response |
| `⌘/` | Open Field Manual |

## Capabilities

- **Chat** — natural conversation, images, file work, shell commands, web search, and edit modes.
- **Collections** — custom schemas for structured lists and tracked items.
- **Media Library** — permanent image storage and retrieval.
- **Sense** — screen awareness, timelines, search, app usage, and session debriefs.
- **Skills** — reusable workflows invoked with `/skill-name`.
